Traefik (recommended for large images)

Ports 80/443 with a Let's Encrypt certificate and no CDN in between, so no request-body limit is imposed on layer uploads. If you also use Cloudflare DNS for the name, keep that record DNS-only (not proxied).

Cloudflare Tunnel (small layers only)

Easiest (no open ports, TLS at the edge), but Cloudflare limits the request body size on proxied traffic and image layer uploads can exceed it. The limit depends on the plan and is not verified here: check Cloudflare's current limits documentation before relying on it. A layer above the limit fails to push with a connection or 413-style error. Keep layers small, push from the Host itself, or use Traefik.

FRP

An FRP tunnel exposes a port but terminates no TLS, so a push through it only works when TLS is handled elsewhere. Mostly not recommended. Yanto does not configure this.
